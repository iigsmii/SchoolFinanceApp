نسخه تعمیر اساسی SchoolFinanceApp – 2026-10-02

این نسخه بر پایه آخرین نسخه دارای تم‌ها ساخته شده و فقط مسیرهای خراب Backend/Frontend را اصلاح می‌کند.

اصلاحات اصلی:
1) لیست مدیران و مدارس برای مدیر ارشد؛ Backend در هر درخواست داده‌های پایه را بدون پاک کردن اطلاعات موجود می‌سازد.
2) لیست هزینه‌ها؛ دسته‌های هزینه در صورت نبودن خودکار ساخته می‌شوند.
3) ثبت هزینه؛ category_id اکنون به نام دسته هزینه تبدیل می‌شود و ثبت تراکنش انجام می‌شود.
4) پیام مدیر ارشد؛ حذف/غیرفعال‌سازی پیام با همان API انجام می‌شود.
5) ورود Excel دانش‌آموزان؛ ردیف عنوان به‌صورت خودکار پیدا می‌شود و فایل نمونه «آقا مهدی.xlsx» با ردیف اول عنوان و ردیف دوم Header پشتیبانی می‌شود.
6) کد ملی در فایل نمونه وجود ندارد؛ ورود دانش‌آموز با کد ملی خالی انجام می‌شود و بعداً قابل تکمیل است.

مهم: فایل SchoolFinanceApp_GoogleAppsScript_FINAL.gs را در Google Apps Script جایگزین نسخه قبلی کنید، Save بزنید، سپس Deploy > Manage deployments > Edit > New version > Deploy را انجام دهید. همان URL /exec قبلی را نگه دارید.

بعد از انتشار Backend، APK را از همین پروژه در CodeMagic بسازید. این محیط Gradle/Android SDK کامل ندارد، بنابراین APK را اینجا ادعا نمی‌کنیم که Build شده است.

نسخه 2.11: ثبت گروهی بدهی شهریه با انتخاب/عدم انتخاب دانش‌آموزان و ثبت گزارش فعالیت مدیران.
