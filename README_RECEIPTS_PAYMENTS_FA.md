# تغییرات بخش دریافت و پرداخت

- صفحهٔ «شهریه و درآمد» در داشبورد با «دریافت و پرداخت» جایگزین شده است.
- چهار عملیات اضافه شده‌اند: دریافت نقدی، پرداخت نقدی، دریافت چک و پرداخت چک.
- فرم‌ها شامل طرف حساب، مبلغ، تاریخ و شرح هستند؛ فرم چک شناسه صیادی، بانک و سررسید را نیز می‌گیرد.
- سوابق این عملیات از فهرست تراکنش‌ها قابل مشاهده است.

## اعمال تغییرات
1. سورس اندروید را با Android Studio باز کنید و Build کنید.
2. محتوای `SchoolFinanceApp_GoogleAppsScript_FINAL.gs` را در پروژه Apps Script موجود جایگزین/ادغام کنید.
3. در Apps Script نسخه جدید را Deploy کنید و آدرس Web App قبلی را حفظ کنید.
4. ابتدا با حساب آزمایشی، هر چهار نوع سند و ریز گردش را تست کنید.

## محدودیت فعلی
این نسخه ثبت پایهٔ اسناد عمومی را به جدول Transactions اضافه می‌کند. تأیید/وصول چک، صدور سند حسابداری دوطرفه، و نگاشت این انواع جدید به خروجی پارسیان هنوز توسعه داده نشده‌اند. برای استفادهٔ حسابداری رسمی، این موارد باید پیش از استفاده عملیاتی تکمیل شوند.
