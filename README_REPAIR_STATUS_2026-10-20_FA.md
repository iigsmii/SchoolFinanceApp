# گزارش اصلاحات SchoolFinanceApp — ۲۰ اکتبر ۲۰۲۶

این بسته یک نسخه کاری بر پایه آخرین ZIP موجود در گفتگو است؛ تا زمانی که Build کامل و آزمون روی شیت واقعی انجام نشود، آن را نسخه نهایی/آماده انتشار تلقی نکنید.

## اصلاحات این مرحله
- صفحه ورود از لوگوی اصلی ارسالی استفاده می‌کند و همان تصویر برای آیکون‌های PWA در اندازه‌های موردنیاز استفاده شده است.
- گزینه «ذخیره نام کاربری و رمز عبور» اضافه شده است. رمز در فضای محلی مرورگر ذخیره می‌شود؛ فقط روی دستگاه شخصی و محافظت‌شده فعال شود.
- ورود پس از تأیید اعتبار، منتظر پایان همگام‌سازی نمی‌ماند و همگام‌سازی در پس‌زمینه آغاز می‌شود.
- با برگشت اتصال اینترنت، همگام‌سازی مجدداً شروع می‌شود.
- همگام‌سازی موجود برای دانش‌آموزان، تراکنش‌ها، چک‌ها، مدارس، مدیران، سرفصل‌ها و تراکنش‌های بانکی از جایگزینی کور داده محلی با پاسخ ناقص/خالی جلوگیری می‌کند؛ در شناسه‌های یکسان، رکورد سرور اولویت دارد و رکوردهای محلیِ بدون همتا حفظ می‌شوند.
- افزودن/ویرایش/غیرفعال‌سازی مدیر به API بک‌اند وصل شده است؛ ستون‌های کارت تنخواه و سقف/مانده تنخواه در برگه Managers تعریف شده‌اند.
- در صفحه بانک، فایل Excel با تشخیص ردیف عنوان و نام‌های متنوع ستون‌ها خوانده می‌شود؛ ردیف‌های فاقد مبلغ معتبر دیگر مبلغ ساختگی دریافت نمی‌کنند.
- تلاش برای بارگذاری XLSX بانک به برگه `Bank` سمت سرور اضافه شده است و نتیجه ذخیره ابری در پیام نشان داده می‌شود.
- تراکنش‌های صورتحساب واردشده، با بخش‌های تطبیق‌شده و تطبیق‌نشده و تعداد جداگانه نمایش داده می‌شوند.
- در صفحه دانش‌آموزان، حذف فیزیکی فقط وقتی مجاز است که گردش مالی مرتبطی وجود نداشته باشد؛ برای دانش‌آموز دارای سابقه، گزینه «انصراف از مدرسه» او را غیرفعال می‌کند و سابقه را نگه می‌دارد.
- غیرفعال‌شدن مدیر یا تغییر رمز/اطلاعات اعتبارسنجی، نشست قبلی را بی‌اعتبار می‌کند؛ انقضای نشست هم بررسی می‌شود.
- workflowها از نسخه‌های جدیدتر checkout/setup-node/setup-java استفاده می‌کنند؛ upload-artifact به v5 تنظیم شده است.

## آزمون‌های انجام‌شده
- ۲۸ آزمون بک‌اند مبتنی بر mock اجرا شد و موفق بود. این آزمون‌ها به Google Sheets واقعی وصل نمی‌شوند.
- بررسی نحوی TypeScript/TSX فایل‌های تغییرکرده موفق بود.
- بررسی نحوی فایل Apps Script با Node.js موفق بود.

## مواردی که هنوز تکمیل یا تأیید نشده‌اند
- اجرای کامل `npm run build` انجام نشد: نصب وابستگی‌ها در این محیط به‌علت نبود دسترسی/کش بسته‌ها تکمیل نشد؛ بنابراین این بسته هنوز Build کاملِ تأییدشده ندارد.
- همگام‌سازی کامل دوطرفه و صف پایدار برای *تمام* داده‌ها هنوز پیاده‌سازی نشده است. حقوق و بیمه، کارکرد کارکنان، تنظیمات، فعالیت‌ها و بعضی داده‌های جانبی هنوز به برگه‌ها/عملیات مستقل و سیاست حل تعارض نیاز دارند؛ برای همین ادعا نمی‌شود که «همه اطلاعات» اکنون به شیت می‌روند.
- تغییرات بانک/مدیران از مسیرهای جدید ارسال می‌شوند، اما آزمون روی شیت زنده و مجوزهای وب‌اپ انجام نشده است. بک‌اند داخل ZIP باید جداگانه در Apps Script جایگزین و Deploy شود.
- دریافت خودکار از `billing.bsi.ir` پیاده‌سازی نشده است. ابتدا باید روش رسمی/مجاز دریافت فایل یا API مشخص شود؛ رمز بانکی نباید در سورس، Google Sheets یا گفتگو ذخیره شود.
- افزودن/ویرایش/حذف کارت تنخواه از مسیر اطلاعات مدیر موجود پشتیبانی می‌شود؛ گردش کامل CRUD برای کارت مستقل از مدیر و همگام‌سازی مستقل آن هنوز نیازمند تکمیل است.
- رفتار بستن پنجره‌های داخلی با کلید Back در همه صفحات، و خروج واقعی روی دستگاه Android باید روی APK واقعی آزمون شود.

## انتشار
برای استفاده آزمایشی، سورس وب و فایل `SchoolFinanceApp_GoogleAppsScript_FINAL.gs` باید با هم نسخه‌بندی شوند. جایگزینی سورس در GitHub به‌تنهایی بک‌اند منتشرشده را تغییر نمی‌دهد. تا پایان موارد بالا، این ZIP را روی داده مالی زنده به‌عنوان نسخه نهایی مستقر نکنید.
