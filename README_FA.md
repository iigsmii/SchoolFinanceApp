# بسته اصلاحات SchoolFinanceApp (بر اساس شاخه main)

این بسته تغییرات هدفمند را روی سورس موجود در مخزن اعمال می‌کند؛ سورس کامل مخزن داخل ZIP نیست.

## تغییرات
1. مقایسه نسخه به‌روزرسانی با نسخه واقعی نصب‌شده، نه مقدار ثابت `2.14.0`.
2. جلوگیری از دریافت APK از نشانی غیر HTTPS و جلوگیری از ادامه دانلود در صورت تغییر مسیر به HTTP.
3. نگاشت مسیر `/api/bank/match` در `ApiClient`.
4. اصلاح تطبیق خودکار بانک: بدهی دانش‌آموز با بانک تطبیق نمی‌شود و یک ردیف بانکی نمی‌تواند برای چند تراکنش استفاده شود. لینک قبلی حفظ می‌شود.
5. اصلاح مسیر تطبیق دستی سمت سرور: جلوگیری از تطبیق بدهی، تطبیق بین دو مدرسه، مبلغ متفاوت و استفاده مجدد از ردیف بانکی.
6. حفظ فیلد `payment_source` در به‌روزرسانی وضعیت تراکنش.

## روش اعمال
1. آخرین شاخه `main` را از GitHub دریافت کنید و ZIP آن را باز کنید.
2. فایل `apply_schoolfinance_fixes.py` را در ریشه پروژه، کنار پوشه `app/` و فایل `SchoolFinanceApp_GoogleAppsScript_FINAL.gs` قرار دهید.
3. اجرا کنید: `python apply_schoolfinance_fixes.py`
4. بررسی نحوی اسکریپت: `node --check SchoolFinanceApp_GoogleAppsScript_FINAL.gs`
5. ساخت Android را با workflow امضاشده فعلی انجام دهید و نصب/به‌روزرسانی را روی دستگاه آزمایش کنید.

اسکریپت قبل از تغییر هر فایل نسخه پشتیبان می‌سازد و اگر متن مورد انتظار با سورس تفاوت داشته باشد، متوقف می‌شود.

## محدودیت مهم
این بسته به مخزن GitHub شما commit/push نمی‌کند و Google Apps Script را در حساب Google شما منتشر نمی‌کند. پس از اعمال، workflow را اجرا کنید؛ سپس فایل Apps Script اصلاح‌شده را در پروژه متناظر Apps Script جایگزین و به‌عنوان نسخه جدید Web App منتشر کنید. قبل از انتشار عملی، آزمون دستی ورود، ثبت شهریه، ثبت هزینه، واردکردن Excel، ریز گردش و تطبیق بانک انجام شود.
