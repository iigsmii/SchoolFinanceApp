# نسخه اصلاح‌شده SchoolFinanceApp

این بسته از سورس ZIP ارسالی شما ساخته شده و اصلاحات هدفمند اسکریپت روی کدها اعمال شده است.

## تغییرات اعمال‌شده
- مقایسه نسخه به‌روزرسانی با نسخه واقعی نصب‌شده، نه مقدار ثابت.
- محدودکردن لینک دانلود به HTTPS و بررسی تغییر مسیر.
- نگاشت مسیر API تطبیق بانکی دستی.
- اصلاح منطق تطبیق بانکی برای کنارگذاشتن بدهی دانش‌آموز و جلوگیری از استفاده مجدد یک ردیف بانک.
- حفظ منبع پرداخت در به‌روزرسانی رکورد تراکنش.

## وضعیت آزمون
- فایل Google Apps Script از نظر نحو JavaScript با `node --check` بررسی شد.
- APK در این محیط ساخته یا امضا نشده است؛ بنابراین این بسته را APK آماده نصب تلقی نکنید.
- تغییرات فایل Google Apps Script در این ZIP به‌تنهایی روی سرور منتشر نمی‌شوند؛ پس از بررسی باید در پروژه متناظر Apps Script منتشر شوند.
- قبل از جایگزینی، از پوشه پروژه فعلی خود نسخه پشتیبان نگه دارید.
