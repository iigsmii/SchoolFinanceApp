# اصلاحات پروژه - ۱۴۰۵/۰۷/۲۲

- گزینه صفحه اصلی «دریافت و پرداخت» به گردش‌کار قبلی و پایدار «دریافت شهریه» متصل شد. صفحه جدید دریافت/پرداخت عمومی که باعث اشکال در تجربه کاربری بود از مسیر برنامه حذف شد.
- عنوان صفحه شهریه به «دریافت شهریه» تغییر کرد.
- نگاشت مسیر `/api/finance-transaction` در ApiClient به عملیات `finance_transaction` اضافه شد تا در صورت استفاده آتی از این API، به عملیات پیش‌فرض `health` سقوط نکند.
- نقش `admin` در بک‌اند به نقش مرجع `senior` نرمال‌سازی می‌شود تا فیلترهای مجوز و داده‌ها یکدست شوند.
- خروجی پارسیان اکنون از شناسه تراکنش به رکورد شهریه و سپس به دانش‌آموز می‌رسد؛ `source_id` تراکنش شهریه شناسه رکورد Tuition است، نه شناسه دانش‌آموز.
- Workflow اصلی CI به اعتبارسنجی ساخت Debug تغییر کرد؛ ساخت و امضای Release فقط در `android-release.yml` انجام می‌شود تا دو workflow خروجی Release متعارض تولید نکنند.

## نکات استقرار

تغییرات Google Apps Script باید در پروژه Apps Script متناظر نیز منتشر شود تا اصلاح نقش‌ها و خروجی پارسیان در سرور فعال شوند. این ZIP به‌تنهایی کد سرور مستقرشده را تغییر نمی‌دهد.
